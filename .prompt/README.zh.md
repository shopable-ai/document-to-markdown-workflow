# 临时提示词目录

这里只保存仍需续接的任务、一次性交接和临时提示词。生产运行不加载本目录。

- 任务完成或提示词被替代后，有追溯价值的移到[历史提示词归档](../archive/prompt-history/README.zh.md)；不再需要的副本删除并同步更新引用。
- 经常手工使用的提示词放在仓库根目录的 [`prompts/`](../prompts/README.md)，包括电子书修复简版和完整版。
- 测试专用提示词仍放在 `tests/prompts/`，与测试夹具和命令一起维护。
