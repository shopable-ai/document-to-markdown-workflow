# 临时提示词目录

这里保存跨对话续接、handoff、一次性执行目标和其他短期提示材料。它们服务于执行过程，不是正式 Workflow、Skill 或契约。

- 新增临时提示词放在本目录，不要放在项目根目录。
- 测试专用提示词继续放在 `../tests/prompts/`，以便和测试夹具、测试命令一起维护。
- 当提示词内容稳定为长期规则时，应迁移到正式文档、Skill 或契约，并删除临时副本。
- 文件名保留主题和日期，避免覆盖历史交接记录；移动文件时同步更新根目录 README 的链接。
- `网页版修复格式化提示词.md` 仅保存早期简短版本作为历史，不参与当前路由；当前通用规则位于
  `../skills/markdown-format-repair/SKILL.md`。
