# 需求发现区

这里保存来源和 AI 推导过程，不保存批准需求。

- [A2 原始请求与来源登记](RAW-REQUESTS.md)：原始请求登记、来源快照和授权边界。
- [A3 需求发现记录](REQUIREMENT-DISCOVERY.md)：事实、样例、反例、冲突、候选与 Unknown。

V2 通过后，本目录整体降为 reference，退出正常设计和执行上下文。只有发生需求变更、冲突、Unknown 复核、追溯审计或基线重建时才重新加载。任何 discovery 内容晋升到 [02 需求说明](../REQUIREMENTS.md) 都必须记录来源、确认人、版本和基线影响。
