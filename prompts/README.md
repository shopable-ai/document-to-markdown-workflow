# 常用手工提示词

## 电子书格式与内容修复

把下面任选一份提示词和**已转换的电子书 Markdown** 一起交给 AI，不需要重新转换原书。两个版本二选一，不需要同时粘贴。

- [简版：单本快速修复](ebook-md-电子书格式内容修复-简版.md)：适合网页版或一次性处理，修复书名和章节层级、排版及明显的 OCR 错误，保留正文含义和图片引用。
- [完整版：详细规则与验收](ebook-md-电子书格式内容修复-完整版.md)：适合结构复杂或需要逐项验收的书稿。基于 VizTell 的完整提示词整理；其中 `temp/` 扫描和书籍子目录的 `index.md` 命名规则，仅在明确指定 VizTell 批处理时适用。

这里的「内容修复」只指纠正可确认的转换错误、清理非正文杂质，不改写或补写原书。这是长期保留的手工参考，不是生产运行时提示词。

- **如果要修复本仓库生成的运行包或页面单元**：使用正式的 [Markdown 修复 Skill](../skills/markdown-format-repair/SKILL.md)，遵守页面标记、图片顺序和写回边界。
- **如果手上还是 EPUB 原文件**：参见[原生 EPUB 转 Markdown](../skills/native-epub-to-markdown/SKILL.md)。

## 目录约定

- `prompts/`：长期复用、由人选择和粘贴的提示词。新增时用主题命名，并在本页注明适用场景。
- `references/prompts/`：工作流提示词，以 Workflow 或契约登记为准；不在这里维护副本。
- [`.prompt/`](../.prompt/README.zh.md)：跨对话临时交接，不放长期手工模板；测试提示词在 `tests/prompts/`。
