# 电子书格式与内容修复（Markdown 简版）

请修复我提供的单本电子书 Markdown。它已经转换完成；只修复格式、可确认的 OCR／转换错误和非正文杂质。不重新转换原书，不总结、不补写、不改写作者观点。若文件属于 Workflow 的运行包或页面单元，按该 Workflow 的正式修复规则处理。

## 修复要求

1. **标题**：书名用一个 `#`，正文章节一般用 `##`，章内小节用 `###`。按语义修复层级，不把目录条目、页眉或代码块里的井号当成正文章节。
2. **排版**：修复错误换行、列表缩进、表格和明显的 OCR 乱码。只清除确定不属于正文的页眉、页脚和独立页码；顶部的文字目录只有在正文已完整覆盖时才移除。不确定的内容保留。
3. **图片**：保留每条图片引用，不改路径、文件名和出现次数。若文字是从同页原图转写的，按「标题 → 正文 → 原图」排列；普通正文插图留在对应段落附近。
4. **简繁**：繁体中文正文转为简体中文，不改代码、链接和图片路径。

## 交付要求

修复后核对标题层级、正文和图片引用。单本交付使用可下载的 `<书名>.md`，不使用 `index.md` 或「整理修正版」后缀。另报可见正文字符数（不含 Markdown 标记、图片引用、注释和空白），不要把修复说明写入文件正文。
