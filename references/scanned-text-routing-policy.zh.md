# 扫描文字页识别与 Markdown 路由策略

## 1. 当前结论

扫描文字页没有固定默认识别模型。Apple Vision OCR、较小视觉模型和 mac96 30B 都是候选；
只有同类真实页面的质量门通过后，才在通过者中选择耗时和资源成本最低的路线。当前小模型尚未
完成真实运行，因此生产默认保持 `calibration-pending`。

## 2. 三阶段边界

1. `text-recognition` 保存不可变的原始可见文字、坐标/置信度或原始模型响应。
2. `markdown-structure-reconstruction` 重建标题、自然段、目录、列表和页眉页脚候选；不删除原文，
   不根据其他页或常识补写结构。
3. `advertising-classification-and-treatment` 使用独立策略分类和提出后续动作。本轮为
   `preserve-only`，不隐藏、不删除、不改写。

微信号、联系方式、二维码附近说明、推广语和其他疑似广告文字必须在前两层原样保留。二维码
图形不解码、不裁剪、不作为读者图片，但这不能成为删除邻近文字的理由。

## 3. 路线选择规则

每一种页面类别分别校准，不能用正文页结论替代目录页、标题页或复杂布局页：

- 普通正文页；
- 标题/封面页；
- 目录与列表密集页；
- 低置信度或低清晰度页；
- 多栏、表格、图文混排及阅读顺序复杂页；
- 跨页续行或跨页结构页；
- 含联系方式、推广语、二维码附近说明等异常文字的页面。

候选路线只有同时满足下列条件才成为该页面类别的 `qualified route`：

- 原始可见文字无静默遗漏，未改写异常文字；
- 标题层级、正文分段、目录、列表、页眉页脚、标点、跨页连续性的适用维度全部通过；
- `hallucinated_structure_count = 0`；
- 原始识别结果、结构结果、图片哈希、来源指纹、模型/引擎、参数、提示词版本和耗时可追溯；
- 资源指标实测或明确写 `Unknown`，不以模型参数量替代实测。

同一页面类别有多条合格路线时，按实测中位耗时、峰值内存/模型驻留内存和重复稳定性选择成本
最低者。不能因为 OCR 快、30B 大、小模型便宜或输出非空就直接设为默认。

## 4. 按页升级条件

当前路线出现任一条件时，只升级当前页，不覆盖上一条路线的原始证据：

- OCR/模型传输、超时或解析失败；
- 低置信候选超过该类别校准阈值；
- 原始文字覆盖失败或发现静默遗漏；
- 标题、自然段、目录、列表或阅读顺序守卫失败；
- 页眉页脚与正文边界未决；
- 标点错误改变语义或目录页码对应；
- 页面起止明显跨页，但连续性无法确认；
- 出现模型补写的标题、编号、页码关系或正文；
- 存在复杂视觉关系，而当前路线只能提供文字。

升级目标必须是同类页面上已经通过真实校准、且当前任务有权调用的下一条候选。所有候选失败时
记录 `failed/unavailable`；有真实文字/结构冲突或人工判断项时记录 `needs-review`。

## 5. 当前实测对路由的限制

- Apple Vision OCR 加当前确定性结构重建在第 1–5 页速度快且逐候选可追溯，但目录章节层级、
  多行条目、标点和第 4→5 页跨页续行未通过，不能直接成为目录页生产主路线。
- 30B v5 在第 2 页生成了较好的目录 Markdown，但双 pass 用时 138.552 秒且视觉层解析失败；
  第 1 页没有输出 Markdown 标题层级。两页证据不足以把 30B 提升为生产默认。
- v6 视觉提示词已经进入规格和测试，但首次 30B 实测因 mac96 SSH `Host is down` 未获得模型输出。
- 小视觉模型尚无真实页面结果；在其结果加入同一基准前，不选择生产默认路线。

[`runs/real/real-runs-20260818-humanity-scripts/recognition-route-benchmark-v1/REPORT.zh.md`](../runs/real/real-runs-20260818-humanity-scripts/recognition-route-benchmark-v1/REPORT.zh.md)。

## 6. 通过标准

路线校准只有在代表性页面覆盖成立、所有适用质量维度有页面图对照、候选小模型有真实结果、
广告策略证明未改变可见文字、失败回退完成回放后才能 `passed`。文件存在、非空输出、Markdown
可打开、SSH/HTTP 可达、模型清单或单页偶然成功均不能判通过。
