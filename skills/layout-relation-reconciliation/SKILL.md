# 版面关系复核

## 职责

复核文字、形状、连线、分组和坐标之间的关系。

## 输入与输出

输入：原生结构、页面图、OCR 候选。输出：reconciled-layout-model。规则：不得把视觉邻近误写成事实关系；必须包含 `unknown_forms`/覆盖声明，说明是否扫描了预设类型之外的颜色、符号、图例、跨区/跨页连接和嵌套关系。无法确认时保留视觉证据并标记 `needs-review`。

## 边界

这是一个可复用能力 Skill，不负责决定整个 Workflow 的顺序、全局失败策略或最终业务验收；这些由所属 Workflow 和阶段门禁负责。

## 交付要求

- 输出必须包含来源、状态和可诊断错误信息。
- 不覆盖来源文件，不写入密钥或认证信息。
- 无法可靠完成时显式返回 `Unknown`、`needs-review` 或对应失败态。

## 最小字段契约

关系记录必须有端点 ID、关系类型、方向/坐标依据、证据来源、置信度和状态。视觉邻近只能写 `candidate`；无法确定方向时保留 `needs-review`，不得升级为事实关系。
