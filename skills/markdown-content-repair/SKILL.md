# Markdown 内容修复

## 目标与边界

把已经进入 Markdown 的提取文字修复为可读、可检索且结构清楚的读者内容：处理断词、断句、错误换行、段落边界、列表结构、标题层级和相邻文字造成的局部标点问题。文字来源可以是原生提取、OCR、视觉模型或它们的组合；本 Skill 不依赖某一种提取引擎，也不负责重新提取文字。

这个 Skill 不是内容改写、摘要、翻译、事实补全、视觉关系推断或图片资产筛选器。它只处理当前 Markdown 中的文字和 Markdown 结构。图片是否保留、移除或重新分类由 `semantic-visual-asset-pruning` 负责。

默认采用“局域网模型优先、通过守卫后直接修复、保留差异”模式。页面视觉模型先生成
`page-units/pNNN.md` 后，当前 Skill 只读取这一页 Markdown；局域网语言模型只负责把已经存在的
文字整理成更稳定的读者层排版，不重新看图、不重新提取、不推断图示关系。局域网结果成功后立即停止
后续模型路径，不调用当前在线模型。局域网不可用、超时、返回不可解析或未通过结构守卫时，默认保持原文件
并标记 `needs-review`；只有本次任务明确授权时，才把同一页输入交给当前在线模型回退一次。

## 输入

必需输入是当前待修复的 Markdown 文本，推荐使用 `page-markdown-unit` 提供的单页工作单元；修复多页时也必须按明确的页面或章节范围分批处理。

可选输入只有调用方明确提供的当前范围文字候选，并且只能作为文字内容校对依据。候选必须由调用方显式提供，
不能因为文件存在就自动读取。局域网模型的默认输入不是图片或证据文件，而是当前页 Markdown 本身。

默认不得读取或加载以下工程文件作为修复输入：`manifest.yaml`、原始 OCR JSON、bbox/坐标数据、置信度、逐页 Vision JSON、`evidence/` 中的解析/复核报告、来源文档、整批其他页面、其他 `page-units` 文件和页面图。它们可以由上游流程保留为不可变证据，但不属于本 Skill 的默认工作上下文。若人工明确提供当前片段的外部校核材料，也只使用该片段，不扩大读取范围。

## 内容修复流程

1. 确定当前修复范围，只打开当前 Markdown 页面单元或明确选定的章节。
2. 先调用局域网语言模型，默认目标为 `ssh mac96` 上的 Ollama 文本模型；请求只带当前页 Markdown 和固定修复提示词。
3. 识别文字问题：断开的词或句、错误换行、段落粘连、列表/标题标记错位、重复片段和相邻文字直接证明的标点问题。
4. 结合当前 Markdown 上下文和显式提供的文字候选提出局部修复。修复结果必须能由当前已有文字或显式候选逐字得到；不得凭常识补字、改写语气或改变事实强度。
5. 对局域网结果执行结构守卫：必须保留页面编号、原始页面图链接和未确认关系边界；不得新增工程字段、跨页内容、摘要或视觉关系。
6. 只有结构守卫通过，才原子写回当前 `page-units/pNNN.md`，并创建或更新 `reviews/markdown-content-repair.yaml` 和页级修复证据；局域网成功后不再调用在线模型。
7. 局域网不可用、超时、不可解析或未通过守卫时，保持原文件不变，状态为 `deferred`/`needs-review`；只有显式授权时，才用同一页输入调用当前在线模型回退一次。
8. 遇到缺字、多个合理断句、无法确认的标题层级、跨页内容或需要视觉关系才能判断的文字顺序时，停止自动修复，状态设为 `deferred`。
9. `rejected` 和 `deferred` 不写回；`applied` 只表示该条修复已经直接写回，不得顺手润色相邻内容。
10. 写回后只验证当前 Markdown 的结构、链接和读者层边界；原始来源证据的完整性由上游包验收器负责。

## 允许与禁止

允许：连接当前 Markdown 中被错误拆开的词或句；恢复段落、列表和标题结构；拆开被错误粘连的句子或列表项；删除当前范围内明确重复的提取片段；修复由现有文字直接证明的局部标点。

禁止：凭语义补字、同义改写、摘要、翻译、事实纠错、跨页拼接、根据常识补全图表关系、依据坐标猜测阅读顺序、批量统一全篇标点、删除或重分类图片资产，或用候选覆盖原始证据。

## 完成检查

- 读者 Markdown 不含“待复核”“原文疑似”“OCR”解释、坐标、置信度、操作理由或审核状态。
- 每个已应用的修复都能回到当前 Markdown 片段，以及显式提供的文字候选（如有）。
- 写回差异只覆盖该提案范围，没有顺手改写相邻内容。
- 当前页的标题、段落、列表、表格和图片链接结构仍可读；完整资产包另由独立验收器检查。

## 边界

本 Skill 是 A5 中紧跟 `page-units/pNNN.md` 生成的受控读者层后续步骤，不替代 A1-A4 提取、
候选分层、视觉关系复核或 A7 包验收。确定的文字结构问题可以直接修改当前页 Markdown；未决候选不写回、
不把候选改成事实，也不删除或修改来源资产。页面阶段门仍以 `page-markdown-unit` 为准；局域网修复是页面单元
生成后的子步骤，不改变单页 → 小批量 → 全量阶段门。
