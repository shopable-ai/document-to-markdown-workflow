需求树与功能树 · 差量

已有中文需求 R01—R11 不重建；以下为建议新增的工作台功能分支。

需求功能当前状态
任务可观察总览、逐本页数、阶段、更新时间、异常已有状态快照，缺 UI
任务可配置多文件拖入、路径、路线、范围、启动预检已有 CLI，缺表单/API
并发可控待提交批次、等待队列排序、请求/实际并发后端目前串行
失败可恢复暂停、续跑、失败定位、定向重试已有部分后端
磁盘可治理占用统计、回收预览、安全回收已有保护，缺统一回收
图片与效率可衡量算法/OCR/模型路由、耗时、调用次数已有部分能力，缺总账

开发顺序

01
需求对账 + 只读工作台

复用已有 run_id 和状态快照；不干预生产。

02
配置与任务控制 API

白名单传参，预检、幂等启动、暂停/恢复语义。

03
同一队列的资源调度

隔离环境验证 1→2→4，并发资源和磁盘预算。

04
缓存清理与识别优化

独立验收、性能对比、故障回归，通过后部署。
