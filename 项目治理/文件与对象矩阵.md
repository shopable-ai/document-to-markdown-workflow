# 文件与对象矩阵

这个文件供维护者查找“某个内容应该写在哪里”。第一次判断业务需求时不需要先读本文件。

## 状态说明

| 状态 | 含义 |
|---|---|
| existing | 当前已有，并承担明确职责 |
| current-create | 当前确实需要，而且已有真实内容可以写 |
| future-locked | 将来需要，但必须等人工门通过 |
| runtime-instance | 只有发生真实运行或变更时才生成 |
| legacy-reference | 旧英文、历史或 Brownfield 参考，不是当前权威 |
| missing-reference | 其他文件声称存在，但现场找不到 |

目录存在只代表容器或资产存在，不代表里面的逻辑对象已经确认。

## 文件关系

- 一对一：一个项目范围只在一个范围文件维护。
- 一对多：一条需求可以对应多条验收、多项任务和多份证据。
- 多对一：多条原话、事实和样例可以共同支撑一条需求。
- 多对多：需求、场景、功能、行为、验收、规格、任务和证据通过后续追溯文件连接。

导航、树、矩阵和机器投影只能引用正式正文，不能形成第二权威。
