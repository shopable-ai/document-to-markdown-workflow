# 现有工程资产索引

这个文件记录当前仓库里已经存在的 Workflow、Skill 和其他工程资产，并只读核对它们已经表达和测试到什么程度，帮助后续验证“现有工程能力是否支持确认后的需求”。

文件存在不代表需求正确、路线获准或资产应继续保留。正式的保留、修改、替换、退役决定要等 C18 完整需求基线后在 C19 形成。

## 当前能力结论

这不是需要从零实现的项目。`document-to-markdown-assets` 已经用 A1—A7 串起来源预检、原生内容提取、视觉资产保留、页面视觉理解、Markdown 组装、命名与来源登记和资产包验收；相关 Skills、Contracts、适配器和测试还覆盖页面级路由、页面单元、静态资源链接、批量、恢复和后台长任务。

这个结论只说明存在较成熟、可工作的工程基础。它不等于 C19 已经完成差距盘点，不等于每项能力满足本轮修复后的 R01—R11，也不等于用户指定的真实来源已经通过。

## 已知结构问题

- 现有 Workflow/source runner 的机器输入范围包含独立图片，但 U-B01 仍未决定它是否是当前业务的同级正式输入；实现现状不能关闭该 Unknown。
- 现有 Workflow 和验收仍保留知识库导入/视觉生成的可选或 handoff 引用；当前业务已明确排除这些下游，它们不得重新进入 active 业务主线。
- 多个文件引用的 requirements/BEHAVIOR-STATE-AND-TEMPORAL-SPECS.md 当前不存在。
- 旧 runs/real/ 与当前新运行目录约定不一致，旧实例暂不移动。
- 两个机器契约仍包含旧三段基线简称，本轮不修改机器文件。
- 现有规格和 Workflow 是否能够从确认后的 Markdown 重建，尚未验证。
- `execution/WORKFLOW-A-EXECUTION.md` 的全量阶段页码标记已按页面阶段门补齐为 `6-total_pages`；仍需随布局测试复核。
- 仓库布局测试仍要求知识库低价值页清洗投影，而当前业务已经退役 R12；该旧测试链必须在 C19 处理，不能反向恢复当前非目标。
