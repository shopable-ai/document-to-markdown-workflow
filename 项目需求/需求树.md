# 需求树

本树只组织 `需求说明.md` 中已经存在的 R01—R11，不增加需求，也不表示工程执行顺序。

```text
当前来源的可信 Markdown
├── 来源边界
│   ├── R01 结果只使用当前来源
│   └── R10 多个来源默认分别转换
├── 内容保真
│   ├── R02 Markdown 必须真正可读、可搜索
│   ├── R03 文字、数字和文档结构必须尽量保留
│   ├── R04 可确认的关系必须得到表达
│   └── R11 只允许不改变原意的轻度整理
├── 视觉边界
│   ├── R05 复杂视觉必须同时可搜索、可核对
│   ├── R06 简单文字内容不保留无价值截图
│   └── R07 必要视觉依据必须完整且最小充分
├── 读者交付
│   └── R08 Markdown 与必要资产必须便于阅读和携带
└── 真实边界
    └── R09 Unknown、冲突和失败必须如实保留
```

完整语义只在 `需求说明.md` 中维护。本树不得补充条件、验收、因果、优先级或新编号。
