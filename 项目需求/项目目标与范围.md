# 项目目标与范围

## 项目定位

这是一个已经形成较成熟转换能力的 Brownfield 项目，不是从空白重新定义“怎样生成 Markdown”。历史人工目标、旧需求，以及现有 Workflow、Skill、Contract、适配器和测试共同说明：项目已经能够覆盖来源预检、内容提取、视觉处理、Markdown 组装、资产包组织和独立验收等环节。

当前任务是在不让工程实现反向定义业务的前提下，从历史人工目标和可运行资产中蒸馏、迁移并校正核心业务语义。现有能力是否逐项满足最终需求，仍要在后续 Brownfield 对账和真实来源运行中验证。

## 项目问题

用户需要的不是一个带 `.md` 扩展名的文件，而是把指定页或完整文档范围端到端转换成可直接使用的结果包。来源文档的含义可能同时存在于文字、数字、章节、标题层级、页面分区、列表、表格、公式、代码、图表、箭头、颜色、位置和图形组合中；转换必须尽量保留这些内容、结构和能够确认的关系，不能只抽取散乱文字、生成摘要或交付部分页面。

“可用”不等于“有文字”。读者应能从连续、结构清楚的 Markdown 理解和搜索来源中已经确认的内容；章节、页面或内容单元应按来源顺序衔接，正文引用的静态资源使用包内相对路径，结果包复制或移动后仍可阅读和复核，而不依赖原始编辑软件、临时工程目录、旧转换结果或固定模板补义。

复杂视觉中的空间、方向、层级、颜色编码、图例、数值对应和整体布局不能被扁平 OCR、摘要或猜测文字替代。结果需要可搜索的 Markdown 表达；在 U-B02 确认允许时，还要随附最小充分的静态视觉依据。两者仍不足以确认时，项目保留已知部分和 Unknown，而不是补造完整答案。

## 使用者

- **人工读者**：脱离原始编辑软件，直接阅读、搜索和使用 Markdown。
- **人工复核者**：在复杂视觉、模糊文字、来源差异或结构疑问处核对必要依据。

## 业务目标

目标按业务价值排序；后项的重要性不降低，但不能压过端到端转换主线。

1. **G01 端到端完成指定文档转换**：用户指定的页或完整文档范围都进入一个连续、可使用的 Markdown 结果，不以文件生成、局部页面成功或摘要代替完整转换。
2. **G02 内容与文档结构保真**：尽量保留文字、数字、章节、标题层级、分区、段落、列表、表格、公式、代码、跨页连续性和能够确认的关系，使结果仍然是一份完整文档。
3. **G03 复杂视觉语义保真**：复杂视觉既有可搜索的 Markdown 表达，也在授权允许时有可核对的静态依据；不能用扁平识别文字、摘要、结构化重述或猜测文字替代原始视觉关系。
4. **G04 形成可携带、可直接使用的结果包**：Markdown 与正文引用的必要静态图片能够一起复制、移动和打开，链接不依赖临时工程目录或外部文件继续存在。
5. **G05 交付可复核且结论不过度**：内容、视觉关系、Unknown、冲突、失败和实际覆盖范围都能被人复查；无法确认的部分不能被猜写或隐藏。
6. **G06 当前来源与多来源边界正确**：单次结果只讲本次指定来源；多个来源默认分别转换，只有用户明确声明候选关系时才比较。该目标主要防止重复转换、多来源运行和旧上下文造成污染，是端到端交付的约束，不是项目存在的首要价值。

## 业务范围

- 处理用户明确指定的 PDF、PPTX，以及以后单独确认纳入的其他来源文档。
- 按用户指定的页码范围或完整文档范围，生成内容连续、结构清楚且与来源对应的 Markdown。
- 保留文字、数字、章节、层级、分区、段落、列表、表格、公式、代码和能够确认的关系。
- 区分简单文字内容和复杂视觉内容：前者可靠表达后不保留无价值截图；后者形成可搜索表达，并在授权允许时随附最小充分的静态核对依据。
- 把 Markdown 和正文实际引用的必要静态图片组织成可携带的结果包；授权不足时怎样处理仍由 U-B02 保持未决。
- 如实保留无法确认、冲突、部分失败和未覆盖范围，并让结果可以接受后续独立验收。
- 用户明确指定候选版本时，保留并比较各自内容、差异和未决项。
- 项目责任在指定范围形成可信、完整、可用、可复核的 Markdown 结果包处结束。

## 硬约束

- 用户指定范围内的内容单元必须有明确覆盖，不能漏失、重复、错序，也不能用局部成功外推整份文档完成。
- Markdown 必须表达来源中能够确认的内容、结构和关系，不能只是文件外壳、固定模板、散乱文字或摘要。
- 简单文字内容可靠表达后不保留无价值截图；复杂视觉必须具有可搜索表达，并在授权允许时保留最小充分的静态视觉依据。
- Markdown 与正文引用的静态资产必须通过包内相对链接一起移动，不能依赖临时绝对路径或工程缓存。
- 看不清、无法确认或相互冲突的内容必须保留 Unknown 或待复核，不能猜写成事实。
- 结果只能讲当前来源；旧示例、历史输出、固定标题、固定正文和固定页面结构不能进入新结果。
- 多个来源默认分别转换；没有用户明确声明候选关系时不得比较、合并或自动选主版本。
- 只允许不改变原意的轻度整理，不允许摘要、扩写、删减、翻译或加入来源之外的解释。

## 非目标

- 不整理文章、课程、笔记、工作方法、营销内容或其他内容产品。
- 不建设知识库、索引、向量检索、问答或多材料内容组合。
- 不摘要、扩写、删减、翻译或加入来源之外的解释。
- 不生成图片，不进行视觉重绘、风格改写或跨项目模板化。
- 不负责 Markdown 交付后的其他下游 AI 工作。

## 阻断型 Unknown

1. **U-B01 其他正式来源类型**：除 PDF、PPTX 外，哪些来源可以成为正式输入；独立图片是同级输入还是文档内资产。
2. **U-B02 视觉资产授权边界**：哪些来源允许随交付保存原图或截图；不允许保存时，可以合法交付到什么边界。
