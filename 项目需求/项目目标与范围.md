# 项目目标与范围

## 项目问题

来源文档的含义可能同时存在于文字、标题层级、页面分区、表格、图表、箭头、颜色、位置和图形组合中。项目需要把这些内容忠实转换成 Markdown，而不是只创建一个文件、抽取散乱文字或生成摘要。

“独立可读”表示读者能够直接从 Markdown 理解和搜索来源中已经确认的内容，不必依赖原始编辑软件、旧转换结果或固定模板补义。正文确有需要的视觉依据必须随 Markdown 一起移动，不能留在临时工作目录或外部路径。

复杂视觉中的空间、方向、层级、颜色编码、图例和数值对应不能由纯文字等价替代，因此需要同时保留可搜索的 Markdown 表达与必要视觉依据。两者仍不足以确认时，项目保留已知部分和 Unknown，而不是补造完整答案。

## 使用者

- **人工读者**：脱离原始编辑软件，直接阅读、搜索和使用 Markdown。
- **人工复核者**：在复杂视觉、模糊文字、来源差异或结构疑问处核对必要依据。

## 业务目标

- **G01 当前来源正确**：结果只讲本次指定来源，不受旧示例、历史输出或其他材料污染。
- **G02 Markdown 独立可读**：结果不是文件外壳、固定模板或摘要，读者可以直接阅读和搜索。
- **G03 内容与关系保真**：尽量保留文字、数字、章节、层级、分区、列表、表格和能够确认的关系。
- **G04 视觉内容可搜索、可核对**：复杂视觉同时具有 Markdown 表达和必要视觉依据；简单文字可靠表达后不保留无价值截图。
- **G05 不确定性真实可见**：无法确认的内容、关系、冲突和失败不能被猜写或隐藏。
- **G06 来源彼此独立**：多个来源默认分别转换，只有用户明确声明候选关系时才比较。

## 业务范围

- 处理用户明确指定的 PDF、PPTX，以及以后单独确认纳入的其他来源文档。
- 为每个来源生成与其自身内容对应的 Markdown。
- 在正文需要时，把必要视觉依据随 Markdown 一起交付。
- 用户明确指定候选版本时，保留并比较各自内容、差异和未决项。
- 项目责任在可信、可读、可复核的 Markdown 交付处结束。

## 硬约束

- 结果只能讲当前来源；旧示例、历史输出、固定标题、固定正文和固定页面结构不能进入新结果。
- Markdown 必须表达来源中能够确认的内容和关系，不能只是文件外壳、固定模板、散乱文字或摘要。
- 简单文字内容可靠表达后不保留无价值截图；复杂视觉必须同时保留可搜索表达和必要视觉依据。
- 看不清、无法确认或相互冲突的内容必须保留 Unknown 或待复核，不能猜写成事实。
- 多个来源默认分别转换；没有用户明确声明候选关系时不得比较、合并或自动选主版本。
- 只允许不改变原意的轻度整理，不允许摘要、扩写、删减、翻译或加入来源之外的解释。

## 非目标

- 不整理文章、课程、笔记、工作方法、营销内容或其他内容产品。
- 不建设知识库、索引、向量检索、问答或多材料内容组合。
- 不摘要、扩写、删减、翻译或加入来源之外的解释。
- 不生成图片，不进行视觉重绘、风格改写或跨项目模板化。
- 不负责 Markdown 交付后的其他下游 AI 工作。

## 阻断型 Unknown

1. **U-B01 其他正式来源类型**：除 PDF、PPTX 外，哪些来源可以成为正式输入；独立图片是同级输入还是文档内资产。
2. **U-B02 视觉资产授权边界**：哪些来源允许随交付保存原图或截图；不允许保存时，可以合法交付到什么边界。
